Kakao Maps API 키 설정

G-Navi를 사용하려면 Kakao Maps API 키가 필요합니다.

  1. Kakao Developers 가입/로그인
  2. 내 애플리케이션 > 앱 추가 > JavaScript 키 복사
  3. 플랫폼 > Web > 사이트 도메인에 현재 URL 등록

API 키는 이 브라우저의 localStorage에만 저장됩니다.
